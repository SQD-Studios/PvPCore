# PvPCore

PvPCore adds various different PvP related features which appear on patterns combined into 1 plugin to make your life
easier.

**Features**:

- CombatTag - Very similar to [this](https://modrinth.com/plugin/combat-tag) one
- Stat Changer - Add or remove damage from the final output from player's using a specific item material or enchantment.
- Explosive Disabler - Disable explosives like Crystals/Anchors and TnT Minecarts from doing damage and destroying
  blocks
- Safe Zones - Block players in combat from entering these areas, and block players attacking from the inside or the
  outside
